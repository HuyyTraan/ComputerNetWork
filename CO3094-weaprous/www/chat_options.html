🚀 P2P Setup Guide

Vì browser không thể tạo TCP server, bạn cần Node.js:

# Terminal 1: Start P2P Client
node p2p_client.js alice
# Terminal 2: Start another P2P Client
node p2p_client.js bob

Sau đó mở P2P UI và kết nối với WebSocket port.

🌟 WebRTC P2P

WebRTC cho phép browser P2P trực tiếp, nhưng cần:

  • Signaling Server: Trao đổi connection info
  • STUN/TURN: NAT traversal
  • Complex Setup: ICE candidates, SDP offers

Có thể implement sau nếu bạn muốn browser-only P2P.
